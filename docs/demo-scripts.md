# TaskForce 演示剧本(固定 3-5 条,彩排通过再演示,不临场发挥)

> 每条含:输入 / 预期轨迹 / 预期输出要点。演示前确认:PG 容器在跑、LLM Key 有效、
> 沙箱隧道已开(剧本 ④)、知识库已有剧本 ③ 的资料。CLI 与 API 双入口均可演。

## ① 长期记忆:记住偏好 → 新会话生效

- **输入**:REPL 说"记住我偏好:分析类回答希望先给结论再给论据"。
- **预期轨迹**:`memory` 节点 → 记忆提案 → `/confirm yes`。
- **预期输出**:确认已记住;`/new` 开新会话后再问"我偏好什么",answer 经 memory_search 检索后答出该偏好(引用 agents.md 与记忆检索)。

## ② 统一 HITL:缺参数 → ask 提问 → 回答继续

- **输入**:"查一下 2024 年 Q3 的营收数据"。
- **预期轨迹**:supervisor 判断缺关键信息(哪家公司/哪年口径)→ `ask` 挂起 → 用户回答"特斯拉" → resume 续推。
- **预期输出**:ask 事件带问题;回答后 LLM 继续作答(联网调研或诚实说明无法获取)。

## ③ 知识库 RAG:上传 PDF → 问答引用

- **准备**:/kb upload 一份 PDF(如 LangGraph 文档摘录)。
- **输入**:"我知识库里关于 LangGraph 条件边怎么写的?"。
- **预期轨迹**:dispatch → retriever(ReAct 检索)→ supervisor → answer。
- **预期输出**:答案引用知识库内容与来源文件,不编造库外信息。

## ④ 沙箱执行:写脚本统计 CSV

- **准备**:沙箱工作区有 `sales.csv`(三行:商品/数量/单价,合计 166);SSH 隧道已开。
- **输入**:"写个脚本统计 sales.csv 的总销售额"。
- **预期轨迹**:dispatch → executor → 工具循环(读文件 → execute_python 计算)→ ResultSummary 带执行效应(warnings 列出"写入文件/执行代码")。
- **预期输出**:金额 **166**,并如实说明代码在远程沙箱执行、工作区读写经沙箱。

## ⑤ 黄金剧本:异步派发多任务 + 自动汇总推送

- **输入**:"对比 LangGraph 与 CrewAI 的优劣,并结合我知识库里的笔记"。
- **预期轨迹**:supervisor 一次派 2×research + 1×retriever(后台线程池并行),立即返回"已派发 3 个后台任务";期间可继续对话(不被阻塞);任务完成后**自动推送汇总(无需询问;若正在提问则答完再推送)**——REPL 由 watcher 线程唤醒,Web 由前端轮询(`GET /chat/tasks`)触发 `POST /chat/summary`,两者共用 `AUTO_NOTICE` 触发语与同一条 `run_turn` 业务层。
- **预期输出**:自动输出的汇总分维度对比(带来源 URL)并引用知识库笔记;某分支失败/空结果时如实告知缺口,不硬凑。

- [ ] ④ 沙箱执行 + 执行效应可见
- [ ] ⑤ 并行可见、一次汇总、来源引用
