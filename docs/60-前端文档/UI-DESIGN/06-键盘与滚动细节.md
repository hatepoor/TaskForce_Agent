## 6. 键盘与滚动细节

### 6.1 键盘

| 快捷键 | 作用域 | 行为 |
|---|---|---|
| `Enter` | Composer | 发送 |
| `Shift + Enter` | Composer | 换行 |
| `Esc` | 全局 | 关闭抽屉 → 关闭弹窗 → 失焦输入框(按此优先级,一次只做一件) |
| `Ctrl/Cmd + N` | 全局 | 新建会话并聚焦输入框 |
| `↑` | Composer 且**为空**时 | 取回上一条发送过的用户文本(仅本地历史,最多 20 条) |

**中文输入法的坑(必须处理)**:`Enter` 发送判断必须维护显式组合态标志——只判 `event.isComposing === false` 在部分输入法下不可靠:

```
compositionstart → isComposing = true
compositionend   → isComposing = false(并忽略紧随其后那一次 keydown)
keydown Enter    → if (isComposing || e.isComposing) return;  否则发送
```

漏了这步,中文用户选词按回车会误发送半截拼音——中文项目最高频的交互事故。

### 6.2 滚动到底策略

MessageList 维护 `isPinnedToBottom`,"贴底"定义为 `scrollHeight - scrollTop - clientHeight <= 48`。

1. **默认贴底**。新轮次开始(用户发送)时无条件滚到底并置 `isPinnedToBottom = true`。
2. **流式输出期间**,每个 token 批次追加后**仅当贴底为真**才自动滚底;为假时**完全不动**——用户上滚看历史时内容绝不跳动。
3. **用户滚动监听**:任何 scroll 事件后重算贴底状态。向上滚超阈值 → false;滚回底部 → 自动恢复 true。被动监听 + 不去抖,用当前值短路,避免自动滚动引起的事件回环。
4. **暂停期间显示回底提示**:列表右下角浮出 48×32 胶囊 `↓ 新内容`,点击回底。流结束后仍在,直到用户回底或发下一条。
5. **挂起卡出现时强制滚入视野一次**。
6. **切换会话**:恢复该会话上次滚动位置,无记录则到底。
7. **不做**滚动锚定补偿。若 markdown 渲染抖动明显,给代码块和表格预设 `contain-intrinsic-size`,不引滚动锚定库。

### 6.3 其他细节

- 代码块:右上角悬停"复制"按钮;超 20 行默认折叠为 12 行 + "展开"。
- 长链接自动断行(`overflow-wrap: anywhere`),不撑破 760px 栏宽。
- 所有 id(doc_id、thread_id、记忆 key)等宽字体 + 点击复制 + 1.5s `已复制` 内联反馈。
- 空列表一律一行灰字说明 + 一个可执行的下一步动作,不放插画。
- 全局禁用文本选区仅限导航轨图标与按钮;正文、id、错误信息**必须可选中**。
