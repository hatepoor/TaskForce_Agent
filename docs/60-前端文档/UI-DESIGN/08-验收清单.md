## 附:一句话验收清单

- [ ] 深色底 + 单一强调色,全屏彩色元素不超过 3 处(导航当前项、主按钮、agent 圆点)
- [ ] 中文输入法按 Enter 选词不误发送
- [ ] 流式输出时上滚内容不跳动,且出现"↓ 新内容"回底胶囊
- [ ] 两种挂起卡按 `interrupt.kind` 正确分派,挂起期输入区禁用
- [ ] 挂起恢复后卡片原地折叠为一行历史,不残留可交互控件
- [ ] 多选上传拆成串行单文件请求,失败项保留可重试
- [ ] MCP 表单切换 transport 不丢草稿,提交只含当前类型字段且带 `transport`
- [ ] 删除类操作全部有确认弹窗,弹窗内完整回显被删对象
- [ ] 界面上没有任何骨架屏、庆祝动画、插画、emoji
