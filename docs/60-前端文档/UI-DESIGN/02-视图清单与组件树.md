## 2. 视图清单与组件树

### 2.1 ChatView(核心)

```
ChatView.vue                        对话主视图:装配列表 + 输入区 + 抽屉,持有 SSE 会话生命周期
├─ SessionList.vue                  上下文栏:新建按钮 + 会话条目列表
│  └─ SessionItem.vue               单条会话:本地标题 + 当前高亮
├─ ChatHeader.vue                   会话标题(可双击重命名,仅本地)、thread_id 复制、详情抽屉开关
├─ MessageList.vue                  滚动容器,负责贴底自动滚动策略,渲染轮次序列
│  └─ TurnBlock.vue                 一个对话轮次 = 用户消息 + AI 区,统一间距与分隔
│     ├─ UserMessage.vue            用户气泡,右对齐,限宽 80%,保留换行
│     ├─ RouteTrail.vue             路由轨迹条:聚合本轮所有 route 事件,默认折叠为一行
│     │  └─ RouteTaskPopover.vue    展开态:逐条列出 agent/task/reason
│     ├─ SubagentBatchCard.vue      子任务批次卡:派发清单 + 状态(见 §3.2 注意)
│     ├─ AssistantMessage.vue       AI 正文,流式纯文本 → 结束后 Markdown,自带光标态
│     │  └─ MarkdownBody.vue        渲染器封装:代码块高亮 + 复制按钮 + 表格/列表样式
│     ├─ InterruptCard.vue          挂起卡容器,按 interrupt.kind 分派
│     │  ├─ AskInterruptCard.vue    问询卡:问题文本 + 内联输入框 + 发送
│     │  └─ MemoryConfirmCard.vue   记忆确认卡:提案预览 + 忽略/记入
│     ├─ UsageBadge.vue             本轮用量一行小字,右对齐
│     └─ ErrorNotice.vue            流中断/失败提示条 + 重试
├─ Composer.vue                     底部输入区:textarea 自适应高度、Enter 发送、流中禁用
│  └─ ComposerHint.vue              快捷键提示 / 当前挂起态提示
├─ DetailsDrawer.vue                右侧抽屉:路由轨迹时间线、子任务清单、进程用量
│  ├─ RouteTimeline.vue             本轮每一步路由的时间线
│  ├─ SubagentSummaryList.vue       子任务卡片列表
│  └─ UsagePanel.vue                进程累计用量 + 本轮增量
├─ EmptyState.vue                   首次进入空态:一句说明 + 3 个示例问句
└─ DeleteSessionDialog.vue          清空当前会话本地视图的确认弹窗(见 §7.3)
```

### 2.2 KnowledgeView

```
KnowledgeView.vue                   知识库管理页:上传 + 列表 + 删除
├─ UploadPanel.vue                  上传区:拖拽区 + 文件选择 + 多文件队列与进度
│  └─ UploadQueueItem.vue           单个文件的 排队/上传中/成功/失败 四态行
├─ DocTable.vue                     文档列表表格:文件名、doc_id、入库时间、操作
│  └─ DocRow.vue                    单行:操作区含"复制 doc_id""删除"
└─ DeleteDocDialog.vue              删除确认弹窗,显示文件名与切片数
```

### 2.3 MemoryView

```
MemoryView.vue                      长期记忆管理页
├─ MemoryToolbar.vue                条数统计 + 关键字本地过滤输入框 + 刷新
├─ MemoryList.vue                   记忆条目列表(按 created_at 倒序)
│  └─ MemoryItem.vue                单条:正文、来源标记(explicit/confirmed)、时间、删除
└─ DeleteMemoryDialog.vue           删除确认弹窗,原文完整回显
```

### 2.4 SettingsView

```
SettingsView.vue                    设置页外壳:三个节的锚点导航(左栏) + 内容区
├─ McpSection.vue                   MCP 服务器管理
│  ├─ McpServerList.vue             服务器列表
│  │  └─ McpServerItem.vue          单条:名称、transport 标记、命令行/URL 摘要、测试/删除/重测
│  ├─ McpServerForm.vue             新增表单:Stdio/Http 分段切换,字段随类型变化
│  ├─ McpTestResult.vue             测试结果:连通 + 工具名列表 / 未连通
│  └─ DeleteMcpDialog.vue           删除确认弹窗
├─ SkillsSection.vue                Skills 只读列表
│  └─ SkillCard.vue                 单个 skill:name、description、目录路径(可复制)
└─ HealthSection.vue                健康检查面板
   └─ HealthCard.vue                三个指标卡:status / db / sandbox,含手动刷新
```

**状态管理**(最小化):`useChatStore`(会话列表、轮次数据、SSE 连接句柄、挂起态)、`useUiStore`(toast)。管理页数据各视图内 `ref` 局部持有 + `useAsync`,不进全局 store。
