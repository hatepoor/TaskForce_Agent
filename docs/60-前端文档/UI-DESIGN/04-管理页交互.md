### 4.1 知识库(KnowledgeView)

```
┌────────────────────┬───────────────────────────────────────────────────────────────┐
│  文档(12)          │  知识库                                       [ 刷新 ]          │
│  ─────────────     ├───────────────────────────────────────────────────────────────┤
│  ● 设计文档.pdf     │  ┌─────────────────────────────────────────────────────────┐  │
│  ● 架构.md          │  │       拖拽文件到此处,或   [ 选择文件 ]                    │  │
│  ○ 论文-2024.docx   │  │       支持 pdf / docx / md / txt,单文件 ≤ 20MB            │  │
│                     │  └─────────────────────────────────────────────────────────┘  │
│                     │                                                               │
│                     │  上传队列                                                      │
│                     │  ✓ 设计文档.pdf            1.2MB · 已入库 84 切片              │
│                     │  ⟳ 架构.md                 上传中 ▓▓▓▓▓░░░░░ 62%               │
│                     │  ✗ 论文.pdf                失败:文件超过 20MB 上限            │
│                     │                                                               │
│                     │  ┌─────────────────────────────────────────────────────────┐  │
│                     │  │ 文件名            文档 ID          入库时间      操作      │  │
│                     │  ├─────────────────────────────────────────────────────────┤  │
│                     │  │ 设计文档.pdf      a3f9c1e2…      09-14 17:2   复制 删除   │  │
│                     │  │ 架构.md           7b2d40aa…      09-13 21:0   复制 删除   │  │
│                     │  └─────────────────────────────────────────────────────────┘  │
└────────────────────┴───────────────────────────────────────────────────────────────┘
```

**上传交互要点**:

- `<input type="file" multiple>` 一次多选,但**接口只接受单个 `file` 字段**——前端**串行拆成 N 个请求**,不并发(入库写库 + embedding 逐块算,同步阻塞)。
- 队列逐项四态:排队中(灰)/ 上传中(进度条,用 `XMLHttpRequest.upload.onprogress`,fetch 拿不到上传进度)/ 已入库(绿勾 + 切片数)/ 失败(红叉 + detail 文案)。失败项保留在队列里可重试。
- `created: false` 提示"该文档已存在,已复用",不算失败也不算普通成功。
- 上传成功后**自动刷新文档列表**,新 doc_id 高亮 2s。
- 20MB 前端先拦一次(`file.size`);后端 400 detail 仍展示(双保险)。
- 删除:确认框显示文件名 + "删除后该文档的向量切片将一并移除,不可恢复";确认按钮 danger;删除中按钮内联 loading,**不整页遮罩**;完成后 Toast 提示,列表行移除(**无行消失动画**)。

```
  │        └──────────────┴────────────────────────────────┘     │
  │                                                             │

  └─────────────────────────────────────────────────────────────┘
```

**字段差异**(严格对齐后端 `StdioServer` / `HttpServer` discriminator):

| transport | 必填 | 可选 | 控件 |
|---|---|---|---|
| `stdio` | `command` | `args: string[]`、`env: Record<string,string>` | args 多行文本按空白切分;env 键值对行编辑器 |
| `http` | `url`(须 `http(s)://`) | `headers: Record<string,string>` | headers 键值对行编辑器 |

**切换 transport 保留已填内容**(各维护一份草稿),**提交只发当前类型字段且必带 `transport` 字段**。提交前前端校验(名称 `^[a-z0-9_-]+$`、必填非空、URL 带协议头)→ `POST /mcp/servers`(name 走 query、body 是 config 对象,封装在 api/mcp.ts;B6 落地后自动切 body 模型,组件无感)→ 成功关抽屉刷列表;422 显示在表单顶部错误条,不关抽屉。**同名静默覆盖**,保存前若 name 已存在需二次确认。

**测试连通性**:按钮变 `测试中…` 并禁用(后端内部 10s 超时,前端 30s)→ 结果就地展开:

```
  ┌─────────────────────────────────────────────────────────────┐
  │ filesystem          [stdio]   已连通 · 9 个工具              │
  │                                        [ 重新测试 ]  [ 删除 ] │
  │ ┌─────────────────────────────────────────────────────────┐ │
  │ │ 工具:read_file · write_file · list_directory … 共 9 个    │ │
  │ └─────────────────────────────────────────────────────────┘ │
  └─────────────────────────────────────────────────────────────┘

  失败时(ok:false 是正常业务返回,不是红色报错):
  │ failed-server       [stdio]   未连通                       │
  │ ┌─────────────────────────────────────────────────────────┐ │
  │ │ 无法连接:命令不存在或启动超时                             │ │  ← --danger 文字
  │ └─────────────────────────────────────────────────────────┘ │
```

**删除**:确认弹窗"将从 `mcp_config.json` 移除该服务器;其工具在下次会话装配时不再可用"。

```
┌────────────────────┬───────────────────────────────────────────────────────────────┐
│  记忆(23)          │  长期记忆            23 条   [ 过滤… ]        [ 刷新 ]         │
│  ─────────────     ├───────────────────────────────────────────────────────────────┤
│  ● uv 依赖管理      │  ┌─────────────────────────────────────────────────────────┐  │
│  ● 本地环境 Windows │  │ 用户偏好用 uv 管理 Python 依赖,不用 pip。                 │  │
│                     │  │ [自动确认]  09-14 17:22                         [ 删除 ]  │  │
│                     │  ├─────────────────────────────────────────────────────────┤  │
│                     │  │ 用户的开发机是 Windows,路径分隔符需注意。                 │  │

└────────────────────┴───────────────────────────────────────────────────────────────┘
```

- 每条展示 `content` 全文(记忆已压缩,不需折叠)、`source` 中文映射(`explicit→用户明示`、`confirmed→自动确认`)、`created_at` 本地时区、删除按钮。
- 删除确认弹窗**完整回显原文**,提示"删除后智能体不再记得这条信息,不可恢复",确认按钮 danger。
- 过滤框是**纯前端 `includes` 匹配**(后端无搜索参数),不假装成搜索接口。
- 空态:居中一行"还没有长期记忆。对话中说出值得记住的信息,或直接说『记住…』"。

### 4.4 Skills 与 Health

**SkillsSection**:纯只读。扁卡:name 等宽字体、description 正文、dir 单行省略 + 复制。顶部说明:"Skills 由 `skills/` 目录下的 SKILL.md 定义,编辑文件后**重启后端**生效"(智能体侧 `_skills_meta` 有 lru_cache,重启才生效)。**不提供任何写操作**。

**HealthSection**:三张并排指标卡 + 手动刷新。`ok` 绿点、`degraded` 黄点;`sandbox` **非 `ok` 一律按异常渲染**(值域不封闭,精确匹配不可靠),原文本作 tooltip/正文直接展示——本地工具里错误信息越直白越好。

```
  ┌──────────────────┐ ┌──────────────────┐ ┌──────────────────┐
  │  状态            │ │  数据库           │ │  沙箱            │
  │  ● ok            │ │  ● ok            │ │  ● unreachable   │
  │                  │ │  PostgreSQL      │ │  连接超时         │
  └──────────────────┘ └──────────────────┘ └──────────────────┘
                                                     [ 重新检测 ]
```
