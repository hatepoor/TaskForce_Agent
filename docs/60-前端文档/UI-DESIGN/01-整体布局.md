## 1. 整体布局

### 1.1 骨架:导航轨 + 上下文栏 + 主区 + 右侧抽屉

四段式。导航轨常驻;上下文栏内容随视图变化(工作台=会话列表,知识库=文档列表,记忆=记忆条目,设置=节列表);右侧抽屉按需出现(本轮详情 / 表单)。

│  ▦   │    帮我对比 pgvec…  │   用户                                         │  ① dispatch ·2项  │

**尺寸**:导航轨 56px 固定;上下文栏 240px,可拖拽(200–320px),可整体折叠为 0;抽屉 360px,不挤压主区宽度(主区先收缩到 min 520px,再考虑覆盖式抽屉)。整体最小可用宽度 1024px,**不设计移动端**。

### 1.2 导航方式

导航轨四个图标 + 底部固定 Health 状态点:

| 位置 | 图标语义 | 路由 | 上下文栏内容 |
|---|---|---|---|
| 1 | 对话气泡 | `/#/chat/:threadId?` | 会话列表 |
| 2 | 文档 | `/#/knowledge` | 文档列表(可折叠隐藏以让出宽度) |
| 3 | 书签 | `/#/memory` | 记忆条目列表 |
| 4 | 滑块 | `/#/settings` | 节列表(MCP / Skills / Health) |

规则:
- 当前项:图标着 `--accent` + `--accent-soft` 淡底,左侧 2px 竖条指示;每项**常驻文字标签**(v1.3 起,10px;原先只有悬停 tooltip,四个图标认不全)。顶部一个品牌标记(与 AI 头像同语义的三点连线)。
- 切视图**不卸载 ChatView**:`<KeepAlive>` 保住对话状态与滚动位置,SSE 进行中切走再切回不丢流。
- 底部 Health 点:绿=ok,黄=degraded,红=请求失败,灰=未知。每 30s 轮询 `/health`(`document.visibilityState` 不可见时暂停),悬停显示 `status / db / sandbox` 明细。**v1.3 起接真数据**:与设置页共用 `composables/useHealthPoll.ts` 的模块级单例(一份状态、一条轮询)。
- **不做的**:面包屑、页签、全局搜索、命令面板、主题切换按钮(主题跟随系统 `prefers-color-scheme`)。

### 1.3 应用外壳组件

```
App.vue
├─ AppShell.vue            四段式栅格容器,管理各栏宽度与折叠状态
│  ├─ NavRail.vue          56px 导航轨:品牌标记、图标 + 文字标签、当前项指示、Health 状态点(真实轮询)
│  ├─ ContextPanel.vue     240px 上下文栏容器,内部按路由切换具体列表组件
│  └─ <router-view>        主区(KeepAlive 包裹)
└─ ToastHost.vue           右下角轻提示(错误/成功,3s 自动消失,最多堆叠 3 条)
```
