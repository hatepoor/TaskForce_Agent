# 本地部署:Skill 与 MCP 存于用户本地文件系统,不入数据库

系统按本地部署形态运行:每个用户在自己电脑上运行完整服务(FastAPI + PostgreSQL 均在本机),多用户指同一实例上的多个账号,而非互联网服务。Skill 与 MCP 服务器因此不存在数据库中:Skill 是本地磁盘上的文件夹(启动/加载时扫描其 description 与路径,调用时才读取完整内容),MCP 是用户本机配置的 MCP 服务器(含 stdio 本地进程)。这样与 Anthropic 的 Skills/MCP 使用体验一致,避免了上传与存储设计;代价是系统无法集中部署,若未来改为中央服务器部署,Skill/MCP 的接入方式需要重新设计。
