## 设计要点

- `tokenize` 必须是模块级**纯函数**,入库(构建 BM25 索引)与查询(关键词检索)双端共用——词表/分词不一致直接崩命中率;
- 用 `cut_for_search`(而非 `cut`):更适合检索场景的召回粒度;
- 过滤单字 token 防噪音(亦是 GIN 方案膨胀的根因,此处防 BM25 被单字噪音污染);
- jieba 专名误切(如"昆玉河"被拆碎)无 userdict 时靠向量路兜底,诚实接受,不上 userdict(本期范围外)。
