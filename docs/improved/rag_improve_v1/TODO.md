## 使用规则

1. **每次开发前先读本文件**,确认当前进行到哪一模块,从第一个未勾选项继续;
2. 任务完成并通过**对应模块文档**的验收命令后,将 `[ ]` 改为 `[x]`;
3. 共享设计(架构/流程/契约/坑)在 [00-方案总览.md](00-方案总览.md),分模块推进看 01~05;
4. 教学模式:业务代码由用户亲手誊写(Claude 给完整代码 + 改动点清单);`tests/` 测试由 Claude 负责。
