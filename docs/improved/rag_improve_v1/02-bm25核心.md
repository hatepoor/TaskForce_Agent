  - `score = Σ 1/(k + rank)`(rank 为该路内排名,从 1 起)
  - 按总分降序取 top_k,**返回 (chunk_id, 融合分) 列表**(完整字段由 03 store 层统一回填)

## 设计要点

- **候选池 M=5**(评审建议,原 3 偏小):召回宽度与精度折中;
- 懒加载 + 脏标记:存量数据零迁移——首次检索全量重建即覆盖,upload/delete 后置脏不即时更新;
- 双检锁:`_ensure_built` 内 `with self._lock:` 双重检查,避免并发重复构建;
- `rrf_fuse` 输入对齐:向量路候选需含 `chunk_id` 键(03 模块 `_search_vector` 的 SQL 补 `c.id AS chunk_id`),关键词路给 `(chunk_id, score)`;融合只依赖**排名**,不依赖两路分数(免归一化);返回的 chunk_id 由 store 层统一回填。
