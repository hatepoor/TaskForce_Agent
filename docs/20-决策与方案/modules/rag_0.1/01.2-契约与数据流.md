## 三、数据流与接口契约

本篇不产数据流,它产出的"契约"是**环境变量表**:全部 `RAG2_` 前缀,由 `config.py` 统一读取(见 [./07-接口设计与移植方案.md](README.md)),**不依赖 `settings/config.py`**,保证目录整体拷走即可用。参数默认值与全局定稿逐字一致。

| 变量 | 默认值 | 说明 | 消费方 |
|---|---|---|---|
| `RAG2_MILVUS_URI` | `http://localhost:19530` | Milvus standalone 地址 | store.py / retrieve.py |
| `RAG2_EMBED_MODE` | `api` | `local` \| `api` 双模式(定稿走 api) | embed.py |
| `RAG2_EMBED_MODEL` | `qwen3-vl-embedding` | api 模式模型名(多模态);local 模式切 `BAAI/bge-m3`(仅文本) | embed.py |
| `RAG2_EMBED_API_BASE` | `https://dashscope.aliyuncs.com/api/v1` | DashScope 端点(喂给 `dashscope.base_http_api_url`;国际站换 dashscope-intl,以官方示例为准) | embed.py |
| `RAG2_EMBED_API_KEY` | (无) | 百炼 API Key(与 `DASHSCOPE_API_KEY` 同值) | embed.py |
| `RAG2_EMBED_DIM` | `1024` | 向量维度;经 `dimension=1024(SDK 顶层参数)` 请求(默认 2560),与 Milvus schema 必须同为该值(见 [./04-嵌入与Milvus索引.md](README.md) §3.3) | embed.py / store.py |
| `RAG2_EMBED_BATCH` | `20` | 单请求内容元素总数上限(文本 ≤20;local 批大小) | embed.py |
| `RAG2_EMBED_IMG_BATCH` | `5` | 单请求图片条数上限(qwen3-vl-embedding 单请求图片 ≤5) | embed.py |
| `RAG2_JUDGE_API_BASE` | (无,填火山方舟地址) | judge 豆包的 OpenAI 兼容 base_url | evaluate.py |
| `RAG2_JUDGE_API_KEY` | (无) | judge 密钥 | evaluate.py |
| `RAG2_JUDGE_MODEL` | (无,填豆包型号) | judge 模型名(独立于旧 LLM 变量) | evaluate.py |
| `RAG2_PARENT_TARGET_CHARS` | `1500` | 父块目标(1200~1800 区间中值) | chunk.py |
| `RAG2_CHILD_TARGET_CHARS` | `450` | 子块目标字符数 | chunk.py |
| `RAG2_CHILD_OVERLAP_CHARS` | `50` | 子块相邻重叠 | chunk.py |
| `RAG2_CANDIDATE_TOP_N` | `20` | 每路召回候选数(top-20) | retrieve.py |
| `RAG2_RETRIEVE_TOP_K` | `5` | RRF 融合后返回数(top-5) | retrieve.py |
| `RAG2_RRF_K` | `60` | RRF 平滑常数 k | retrieve.py |

约定:judge 三件套**不复用** `.env` 旧 LLM 变量——评估配置自成一体,后续新旧系统同集对比(见 [./06-ragas评估.md](README.md))时才不会互相牵连。

各分篇补充变量(本节为总表,语义以分篇为准;落地时一并进 `config.py`):

| 变量 | 默认值 | 说明 | 消费方 |
|---|---|---|---|
| `RAG2_HNSW_EF` | `96` | 查询期 ef(区间 64~128;见 [./04-嵌入与Milvus索引.md](README.md) §4.4) | retrieve.py |
| `RAG2_DO_OCR` | 关 | 扫描件 OCR 总开关;语义与代价见 [./02-文档解析与噪声处理.md](README.md) §4 | parse.py |
| `RAG2_IMAGE_DESC` | `off` | 图片描述开关 `off` \| `vlm` \| `ocr`(默认关;开启前想清代价,见 模块 02) | parse.py |
| `RAG2_IMAGE_DIR` | `data/rag2_images/` | 抽取图片落盘目录(按 doc_id 分子目录) | parse.py |
| `RAG2_IMAGE_FORMAT` | `png` | 落盘格式 `png` \| `jpg` | parse.py |
| `RAG2_SHORT_LINE_MAX` | `30` | 超短行合并阈值(见 [02.3-实现要点](./02.3-实现要点.md) §4) | parse.py |
| `RAG2_HF_GEOMETRIC` | 关 | PDF 页眉页脚几何规则保留位(本期不实现,仅留开关位) | parse.py |
| `RAG2_VLM_API_BASE` / `_API_KEY` / `_MODEL` | (无) | 仅 `RAG2_IMAGE_DESC=vlm` 时使用,与 judge 三件套分开 | parse.py |
