## 六、与其它模块的依赖关系

本篇是 02~07 全部分篇的**前置**,自身不依赖任何分篇:

| 分篇 | 从本篇拿什么 |
|---|---|
| [./02-文档解析与噪声处理.md](README.md) | docling 依赖、HF_ENDPOINT(模型下载)、首次运行下载模型的预期 |
| [./03-父子分块策略.md](README.md) | RAG2_PARENT_TARGET_CHARS / RAG2_CHILD_TARGET_CHARS / RAG2_CHILD_OVERLAP_CHARS |
| [./04-嵌入与Milvus索引.md](README.md) | pymilvus>=2.5、Milvus 19530(WSL docker)、多模态 embedding(百炼 qwen3-vl-embedding)与 local 备选对比、BM25 备胎包 |
| [./05-混合检索与RRF融合.md](README.md) | RAG2_CANDIDATE_TOP_N / RAG2_RETRIEVE_TOP_K / RAG2_RRF_K |
| [./06-ragas评估.md](README.md) | ragas/langchain-openai 依赖、RAG2_JUDGE_* 三件套 |
