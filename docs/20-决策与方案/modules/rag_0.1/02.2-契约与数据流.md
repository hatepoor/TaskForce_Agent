## 三、数据流与接口契约

```text
路径(str|Path)
  │ parse.py: 后缀白名单 → DocumentConverter.convert() → DoclingDocument
  ▼
DoclingDocument ──(遍历 items: 标题栈 / 表格转 MD / 图片落盘)──► ParsedDoc(原始)
  │ clean.py: 纯函数五条规则(不改顺序、不跨 item 移动内容)
  ▼
ParsedDoc(清洁) ──► 模块 03 chunk.py(父块聚合用标题边界, 子块用递归切分)
```

**`ParsedDoc`**(本篇产出, 字段语义如下; 形状以 [./07-接口设计与移植方案.md](README.md) 为准):

| 字段 | 说明 |
|---|---|
| `doc_id` | 文件字节流 SHA-256 前 16 位 hex, parse 阶段计算(§2.6) |
| `source` | 相对语料根的 POSIX 路径, 与 chunk 元信息 `source` 同源 |
| `items` | `list[ParsedItem]`, 按文档阅读顺序排列 |
| `meta` | dict: 后端类型 / 页数 / 解析耗时 / warnings(字体映射失败等), 由 `ingest.py` 汇入 `IngestReport` |

**`ParsedItem`**(最小字段集):

| 字段 | 说明 |
|---|---|
| `type` | `text` \| `table` \| `image`, 直通 chunk 元信息的 `chunk_type` |
| `text` | 正文原文 / 表格 Markdown / 图片占位文本(非空) |
| `heading_path` | 标题面包屑, 各级以 `" > "` 连接([03.2-契约与实现](./03.2-契约与实现.md) §4.5 全模块约定); 无上级标题为 `""` |
| `page_no` | `int \| None`: pdf 取 `prov.page_no`; docx/md 无页码概念记 `None`(落库时由 模块 04写成 `-1` 哨兵, 见 模块 04坑位 7) |
| `level` | `int \| None`: **仅标题条目有值**(见下方对齐约定 1), 其它为 `None` |
| `image_path` | 仅 `type=image` 有值(相对 `RAG2_IMAGE_DIR` 的路径; 模块 04据此取图做多模态嵌入), 其余为 `None` |

**两条接缝约定(写代码前先记住)**:

1. **标题自身也产出条目**: 标题文本是检索关键词的载体, 同时是 模块 03父块的边界信号。约定为 `type="text"` 且 `level=<层级>` 有值, 其 `heading_path` **只含上级路径(不含自身)**——这样"标题不参与超短行合并、不被并进正文"是自然结果, 模块 03的标题栈也能直接 push。
   *命名对齐*: 模块 03骨架里的 `doc.units` 即本表的 `items`、`unit.kind == "heading"` 与本篇 `type == "text" and level is not None` 是同一信息的两种写法, `unit.char_len` 即 `len(item.text)`; 落地时以 `contracts.py` 定稿的字段名为准, 本表为准绳。
2. **`image_path` / `level` 都不属于九个固定 chunk 元信息字段**(`chunk_id, parent_id, doc_id, source, page_no, heading_path, chunk_type(text|table|image), char_len, created_at`, 父块同携、`parent_id` 为空)。图片路径落库时随其余透传元信息进 模块 04的 `metadata(JSON)`(并作为 模块 04读取图片本体做多模态嵌入的入口), 九字段命名不增不改。

**清洗统计**不新增契约类型: `clean.py` 返回 `(ParsedDoc, dict)`, dict 固定五个键——`{"garbled": 清掉的乱码字符数, "dropped_hf": 跨页重复的页眉页脚条目数, "deduped": 相邻重复条目数, "merged_short": 被合并的超短行数, "dropped_pagenum": 删掉的纯数字残片数}`(第五个键是规则 (5) 的附带项, 落地时补入), 由 `ingest.py` 汇总进 `IngestReport`; 另把规则 (1) 的两类解码级告警写进 `ParsedDoc.meta["warnings"]`。
