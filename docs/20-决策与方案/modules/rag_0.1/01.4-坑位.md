### 4.5 坑位清单

1. **milvus-lite 出局的原因要记牢**:不是"不好用",是官方不支持 Windows;文档教程里的 `MilvusClient("./milvus.db")` 写法在本机直接跑不了,别照抄。
2. **pymilvus 与 server 版本组合**:客户端 >=2.5 只是下限;若 `uv.lock` 解析出 2.6.x 客户端配 2.6.x server 最稳。BM25 Function + jieba analyzer 建表期才真正触发,**冒烟清单只验连接,该能力的实测在 模块 04验收**(全局定稿风险注记)。
3. **首次 docling 调用会"假死"**:在下载模型,受 `HF_ENDPOINT` 影响;没设镜像时可能长时间无输出后超时。可先用第五节的 embed 冒烟验证镜像连通,再跑解析。
4. **Windows GBK 坑**(项目已知):冒烟命令里打中文,用 `uv run python -X utf8 -c "..."` 或先 reconfigure stdout,否则 print 中文可能 UnicodeEncodeError。
5. **ragas 迭代快**:`ragas.metrics` 各指标 import 路径、`evaluate` 参数在 0.1→0.2 有破坏性变化,0.2+ 内部仍可能微调,模块 06落地时以锁版本实测 API 为准,不凭记忆写 import。
6. **9091 端口**:仅健康检查/指标用,被占用可从 ports 删掉该行,不影响 19530。
7. **attu 首次进会要求填 Milvus 地址**:compose 内已由 `MILVUS_URL: milvus-standalone:19530` 带出,直接用即可;Windows 侧浏览器开 `http://localhost:3000`(WSL 端口转发)。纯可选组件,坏了不阻塞主线。
8. **WSL 部署的两个常见坑**:数据卷不要落在 `/mnt/*`(Windows 盘)上,跨文件系统 IO 会让 Milvus 慢一个量级且权限位异常;WSL 内存不足时 standalone 反复重启(表现为 19530 连不上),先在 `.wslconfig` 给足内存再排其它。
9. **百炼多模态接口约定**:单请求内容元素总数 ≤20(其中**图片 ≤5**、视频 ≤1),文本/图片分别按 `RAG2_EMBED_BATCH` / `RAG2_EMBED_IMG_BATCH` 分批;维度经 `dimension=1024(SDK 顶层参数)` 指定(参数名是 `dimension`,默认 2560),改维度必须同步重建 collection;图片传 Base64 或公网 URL(本地落盘 PNG 转 `data:image/png;base64,...` 即可,不必自建图床),**单图 ≤10MB**。实测(dashscope 1.27.6): 维度必须作为顶层参数 `dimension=1024` 传入——写成 `parameters={"dimension":1024}` 会被静默忽略并返回默认 2560。
10. **ragas 装不进主环境(实测 2026-09-20)**: `ragas>=0.4` 经 instructor 钉 `rich<15`(0.4.2~1.8.3 更严,`<14`),与主项目 `rich>=15.0.0` 互斥,uv 直接报 unsatisfiable;降到唯一可解析的 `ragas==0.3.1` 又 `import` 即崩(`ragas/llms/base.py` 引 `langchain_community.chat_models.vertexai`,该模块已从 langchain-community 0.4 移除)。两条出路(模块 06落地时二选一): (a) 评估独立 venv(推荐,主环境零改动); (b) 主项目把 `rich` 放宽到 `<15` 再装(动主线依赖,须回归测试)。
11. **Milvus 落地两个实测坑**: (a) compose 文件名非默认名(`docker-compose.milvus.yml`)时**必须 `-f` 显式指定**,否则报 `no configuration file provided`; (b) Docker Hub 上 `minio/minio` 已取不到 tag,改用 `quay.io/minio/minio:RELEASE.2025-04-22T22-12-26Z`,且新版用 `MINIO_ROOT_USER`/`MINIO_ROOT_PASSWORD`(旧 `MINIO_ACCESS_KEY` 已废弃)。仓库根已有 `docker-compose.milvus.yml`,WSL 侧放 `~/milvus/`(=数据卷目录),三容器 healthy、客户端 19530 已连通(server 2.6.0)。
