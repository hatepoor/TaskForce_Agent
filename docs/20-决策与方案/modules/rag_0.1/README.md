## 二、实现落点(`src/rag_v01/`)

| 模块 | 落点 |
|---|---|
| 00 总览 | 无独立落点: 契约汇总在 `contracts.py`, 参数汇总在 `config.py` |
| 01 环境与依赖 | 无业务代码: pyproject `rag2` extra / Milvus compose / `.env` 段(落地阶段配置) |
| 02 文档解析与噪声处理 | `parsers/`(`pdf.py` / `docx.py` / `md.py` / `common.py` / `images.py`)+ `clean.py` |
| 03 父子分块策略 | `chunk/`(`parents.py` / `children.py` / `common.py`) |
| 04 嵌入与Milvus索引 | `embed.py` / `store.py` |
| 05 混合检索与RRF融合 | `retrieve.py` |
| 06 ragas评估 | `evaluation.py`(不叫 `evaluate.py`, 避免与 facade 公开函数同名) |
| 07 接口设计与移植方案 | `__init__.py` / `config.py` / `contracts.py` / `pipeline.py`(不叫 `ingest.py`)/ `cli.py` / `tests/` |

另: `load.py` 是 docling 解析 `.docx` 的独立示例脚本(教学用), 不在流水线内。
