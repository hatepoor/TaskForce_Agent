## 一、测试(智能体负责)

- `tests/test_react_extract.py`(或并入现有):`extract_answer` 三元组——JSON 带 report / 不带 report / 非 JSON fallback 三分支;conclusion 200 字截断;
- `validate_report` 四分支:缺失 / 过短(<80) / 照抄 key_points / 合格;
- finalize 重试行为:success+不合格 → **恰好一次**重试且重试 LLM 收到的消息以重试指令结尾;重试合格 → summary 三字段更新;重试仍不合格 → report 空串且**无第二次调用**;partial / need_clarification → 不触发重试;
- research/executor/retriever 收尾单测:success 摘要 `report` 字段落进 ResultSummary;partial 分支 report 为空;retriever 的旧自然语言收尾走 fallback 不崩(过渡兼容);
- `test_answer.py`(或并入现有):成稿优先注入(含 `REPORT_MAX_CHARS` 截断断言)、无 report 回退 evidence 渲染;
- 全量 `uv run pytest -q` 回归。

## 二、验收

1. 全量测试绿;

3. REPL 轨迹与 plan 流程不回归(决策字段没动,supervisor 应零感知)。
