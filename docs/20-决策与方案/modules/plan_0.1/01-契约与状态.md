```python
class PlanStepDraft(BaseModel):
    id: str                  # "s1"~"s5",依赖引用锚点
    title: str               # todolist 一句话展示
    detail: str              # 自包含任务描述:目标+输入+输出要求+成功标准
    assignee: Literal["retriever", "research", "executor"]
    depends_on: list[str] = Field(default_factory=list)

class PlanDraft(BaseModel):
    goal: str                # 用户目标回显(锚定意图)
    steps: list[PlanStepDraft] = Field(min_length=1, max_length=5)
```

### 1.2 校验规则(PlanDraft.validate_structure(),纯函数,失败抛 ValueError)

| 规则 | 内容 | 原因 |
|---|---|---|
| id 格式 | 匹配 `^s\d+$` 且全唯一 | 依赖引用的锚点必须无歧义 |
| 依赖存在 | depends_on 里的 id 必须出现在 steps 中 | 防悬空引用 |
| 只向前引用 | 依赖步的 id 字典序必须严格小于自身 | 结构性防环,省去图算法 |
| 步数 | 1 ≤ n ≤ 5 | 与 MAX_PARALLEL_SUBAGENTS=3 及 recursion_limit 预算对齐 |

### 1.3 Plan(运行时状态形状)

```python
class PlanStep(BaseModel):
    id: str
    title: str
    detail: str
    assignee: Literal["retriever", "research", "executor"]
    depends_on: list[str] = Field(default_factory=list)
    # ---- 以下为运行时字段,LLM 不填,代码维护 ----
    status: Literal["pending", "running", "done", "failed", "skipped"] = "pending"
    task_id: str = ""        # 派发后回填,与 ResultSummary.task_id 对账(summary.py:22)
    result_digest: str = ""  # 完成后回填 r.conclusion,供收口汇总与后续步提示

class Plan(BaseModel):
    goal: str
    steps: list[PlanStep]
```

行为方法(放模型上,保持节点薄):

- `ready_steps()` — pending 且 depends_on 全 done,保持原顺序
- `mark_by_task(task_id, summary)` — 按 task_id 对账:`failed`→failed(级联下游),其余(success/partial/need_clarification)→done——"缺澄清"不是硬失败,digest 带缺口说明供下游补救(2026-09-24 冒烟修正);回填 result_digest
- `cascade_skip()` — failed/skipped 的直接依赖迭代传播至不动点
- `snapshot()` — 渲染进度快照文本(格式见 03 §5)
- `finished()` — 无 pending 且无 running

`PlanDraft.to_plan()` 负责装配(逐字段拷贝,运行时字段取默认值)。
