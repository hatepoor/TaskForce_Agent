# v1 即采用多用户体系(用户名密码 + JWT)

项目虽为个人学习项目,但用户决定从一开始就按多用户设计:用户名密码注册/登录,JWT 鉴权,密码 bcrypt 哈希存储于 PostgreSQL。会话线程、长期记忆、知识库均按用户隔离。这一决定意味着数据模型(长期记忆与知识库记录均携带 user_id)与 API(全部需要鉴权)从第一版起就是多用户形态,后续无需迁移;代价是 v1 需要承担用户管理模块的实现成本。

> 2026-08-28:被 ADR-0005 取代。v2 回归单用户、无鉴权,数据表保留 user_id 列(默认 'local')作为扩展点,其余多用户设计移入 backlog。
