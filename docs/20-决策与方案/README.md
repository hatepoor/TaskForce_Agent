# 20-决策与方案

> 一句话: 项目怎么定的(决策)+ 打算怎么做(方案) —— 决策记录、方案定稿与现行模块方案树。
> 体系: 决策与方案 · 目录导览
> 上下游: 上游 [10-项目概览](../10-项目概览/README.md) · 下游 [30-开发过程](../30-开发过程/README.md)

## 三个子域

| 子目录 | 内容 | 状态 |
|---|---|---|
| [adr/](adr/README.md) | 架构决策记录 0001~0012(含被否决项;**编号被 src 注释引用,文件不可改名**) | 🟢 现行 |
| [design/](design/README.md) | 方案定稿:DESIGN(定位与能力)、PROMPT-DESIGN(上下文与提示词,§编号被 src 注释引用) | 🔵 参考 |
| [modules/](modules/README.md) | 现行模块方案树(**唯一口径**):rag_0.1 / plan_0.1 / agent_opt_0.1 | 🟢 现行 |

## 读法

- 想查"为什么这样设计" → `adr/` 找编号;
- 想看"某个模块怎么做" → `modules/<方案>/README.md` 起步(rag_0.1 为拆树先例);
- 新方案文档一律建在 `modules/` 下(按 rag_0.1 先例拆文档树, 单文件 ≤200 行)。
