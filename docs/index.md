## 原子化规范(所有文档适用)

1. **单文件 ≤200 行**, 超限即拆(拆分沿内容类型边界; 分片保留原编号前缀, 同构命名);
2. 每篇头部带**定位块**: 一句话用途 + 所属体系 + 上游/下游各 1 条;
3. **自包含**: 不写"如前述/见上文"; 跨文档只留"细节见 X"式导航链接; 跨模块引用优先指向对方 README;
4. 每个目录一个 `README.md` 作原子索引。
