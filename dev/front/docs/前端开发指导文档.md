## 项目概述

为 TaskForce(LangGraph 单用户本地 Agent 工作台,后端 FastAPI 六 router 已就绪)构建 Vue 3 前端工作台。目标用户是开发者本人,数据不出本地。工程位于 `dev/front/`,完全独立于 Python src 六包,不进 uv / pytest / hatchling。

## 技术栈(全局规范)

| 层 | 选型 |
|---|---|
| 框架 | Vue 3.5 `<script setup>` + Composition API |
| 语言 | TypeScript ~5.7,strict 全开(见 ARCHITECTURE §1.4) |
| 构建 | Vite 7,hash 路由(vue-router 4),Pinia 3 |
| 样式 | 原生 CSS 变量 token(UI-DESIGN §5.3)+ scoped,零 UI 库 |
| Markdown | marked + dompurify |
| 测试 | Vitest,只测纯函数(帧解析等) |
| 部署 | 生产构建产物由 FastAPI StaticFiles 挂载(形态 B) |

## 硬性纪律

1. **教学模式**:前端业务代码由用户按 task 文档亲手誊写;配置类(脚手架/vite.config/.env/tokens.css)与测试代码(Claude 负责写 `tests/` 下后端测试;前端 Vitest 用例同样由 Claude 给全文)不是学习重点。
2. **契约唯一事实源**:任何类型与 [API-CONTRACT.md](API-CONTRACT.md) 冲突时以契约为准;改契约先在 `docs/dev/ROADMAP.md §7` 登记。
3. **BaseURL 只在 `src/api/http.ts` 一处拼接**(VITE_API_BASE:开发 `/api`,生产空)。
4. **后端全同步红线**:所有后端改造不得引入 async,不得修改 `agent/contracts/`。
5. 每完成一个 task 更新模块 todolist,模块全部完成更新项目 todolist 并解除下游依赖。
6. 每个模块验收跑 `npm run build` + `npx vue-tsc --noEmit` 双绿。

## 设计原则(摘自 UI-DESIGN §0.1,全模块适用)

工具不是产品;信息密度优先;状态用克制的元素表达;唯一强调色 `#5b9dff`;动效仅 hover 过渡与轨迹点呼吸;无骨架屏/插画/emoji;中文输入法 Enter 组合态必须处理;删除类操作必须确认弹窗并回显原文。
